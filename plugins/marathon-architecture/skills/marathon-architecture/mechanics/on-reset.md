# on-reset

1. At a closeout, take each note that the work validated and showed to apply beyond this
   repository, and land it:
   - **Standalone**: write it as a page under `architecture/` in this session, and delete the
     note.
   - **Workspace**: land it as a note in the architecture repository's `context/`. That
     repository writes the page in a session of its own. The member's note stays until the page
     exists.
2. Record **Promoted** for the note that moved. A standalone promotion records nothing else for
   it. Record **Integrated** for a member's note once a page replaces it, and **Cross-repo** for
   anything written in the architecture repository.
3. At a handoff, promote nothing. Name the candidate in the Disposition for the closeout.
