# on-reset

1. On a closeout, take any settled note the work showed to have generalized past this repository
   and land it:
   - **Standalone** — write it as a page under `architecture/` this session and delete the note.
   - **Workspace** — land it as an open note in the architecture repository's `context/`, which
     authors the page in a session of its own. The member's note stays until the page exists.
2. Record **Promoted** for the note that moved (a standalone promotion records nothing else for
   it), **Integrated** for a member's note a page later lets go, and **Cross-repo** for anything
   written in the architecture repository.
3. On a handoff, promote nothing; note the candidate in the Disposition for the closeout.
